## Decisions
- **SUPERSEDED — scripts became markdown.** First pass shipped runnable `.py`
  scripts; the user asked for `.md` instead. See "Converted to markdown" below.
  The original reasoning against *notebooks* still holds (jupyter dependency,
  bad diffs, stale embedded output).
- **Each teaches the trap before the fix.** The API's shape only makes sense once
  you've seen what it prevents, so `02` shows an upsert visibly *failing* to
  remove a restated row before introducing `replace_window`; `03` shows a plain
  cache rejecting repeated timestamps before declaring `identity_columns`.
- **Tested by glob, with guards against a hollow suite.** Discovery is
  `glob("[0-9]*.py")` so new tutorials are covered automatically — but an empty
  glob would make a parametrized suite pass vacuously, so there's an explicit
  `test_tutorials_are_discovered`. Also asserts each script has a module
  docstring and a row in `tutorials/README.md`.
- Verified the smoke test actually catches breakage by injecting a typo into
  tutorial 01 and confirming a red run, then restoring. Worth doing — a test that
  shells out and asserts on a return code is easy to get silently wrong.
- Added `PandasTimeseriesCache.row_key` rather than let a tutorial reach into
  `_cache`; an example that demonstrates poking at privates teaches that.

## Gotchas & dead ends
- Tutorial 01 originally said "the second and third calls" when the run only made
  two — caught by reading the actual output rather than trusting the prose. Worth
  running every example and reading it end to end, not just checking exit 0.
- The gap after extending a range starts at `+1us`, which looked like an off-by-one
  until I remembered closed intervals. Left it visible in the output (switched the
  call log from `%Y-%m-%d` to isoformat) and explained it — it's a good teaching
  moment for the discrete-microsecond domain rather than something to hide.
- `ruff format` split a couple of long f-string prints across lines; assigning to a
  local first reads better than letting it wrap mid-expression.

## Converted to markdown (same session, after user feedback)
- Tutorials are now five `.md` pages. The property worth keeping from the scripts
  was that the code demonstrably runs, so `test_tutorials.py` now **extracts every
  ```python block, concatenates in document order, and executes it**.
- Two conventions this forces, both deliberate: blocks build on each other into one
  runnable script, and prose claims are written as `assert`s. That means the test
  validates the *narrative*, not just that nothing raised — verified by flipping an
  assertion and confirming red, as well as by breaking an API call.
- Non-executable snippets (e.g. the conftest fixture quoted from the repo) are
  fenced ```py or ```text and skipped. Also asserted: index membership and that
  inter-page links resolve.
- **`ruff format` reaches inside markdown code fences.** Confirmed by mangling a
  line inside a fence and seeing `--check` fail. So tutorial code is style-checked
  for free — don't assume markdown is outside the linter's reach.
- Writing the asserts caught a wrong claim: rows sort by the full row key, so a
  later-timestamped trade sorts after same-instant prints regardless of its id. The
  page now teaches that instead of asserting the wrong order. Strong argument for
  asserts over pasted output.
