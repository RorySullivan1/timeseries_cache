## Gotchas & dead ends
- **Remote branch deletion is blocked in this environment.** `git push origin
  --delete` and the `:branch` refspec form both return **HTTP 403** from the
  session's git proxy — a policy, not a transient failure, so retrying is
  pointless. There is no delete-branch tool in the GitHub MCP either. Local branch
  deleted; `origin/claude/timeseries-cache-template-pq0v1e` still exists and needs
  a click in the GitHub UI. Expect this again on every future branch cleanup.
- **CI immediately caught a config bug**, which is the argument for having it.
  `[tool.mypy] python_version = "3.11"` looks obviously right — it's the floor in
  `requires-python` — but it makes 3.12 and 3.13 fail on *numpy's own stubs*,
  which use `type` statements a 3.11 target rejects as a syntax error. Removed the
  pin: mypy now targets the interpreter it runs under, and the 3.11 matrix job is
  what guarantees the floor. That's the stricter check anyway (real 3.11 semantics
  rather than a config assertion). Left a comment in pyproject.toml, because
  re-adding the pin is the obvious "fix" for anyone who doesn't know why it's gone.
- Ran the whole matrix locally with `uv run --python 3.1x` before pushing, which is
  how the mypy failure surfaced before CI rather than after.
